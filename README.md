# Bumbu 🐙

A tiny pink octopus that follows your cursor around Windows and says cute things.

- **Run:** `python bumbu.py` (Python 3 on Windows, no extra deps)
- **Build exe:** `build.bat` → `dist\Bumbu.exe` (or grab the artifact from the GitHub Actions run)
- **Double-click** Bumbu to make it talk, **right-click** to quit.
